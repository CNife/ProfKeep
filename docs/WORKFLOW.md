## GitHub 工作流

1. 选择无阻塞或阻塞已完成的 issue
2. 开发完成后：
   - 提交代码并推送
   - 更新 `docs/WORKFLOW.md` 中的 Issue 状态表
   - 关闭 issue 并添加完成评论（列出完成内容、验收结果、提交 SHA）
3. 分支命名：`issue-<number>` 或功能分支名

## 提交推送规则

完成一段相对完整的工作后，提交变更并推送：
1. **检查分支**：确认当前不是 main 分支
2. **提交**：简短提交信息，无前缀
3. **推送**：`git push`
