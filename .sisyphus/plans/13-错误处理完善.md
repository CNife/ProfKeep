### 错误类型处理

| 错误类型 | 用户提示 |
|---------|---------|
| 网络超时 | 网络超时，请稍后重试 |
| Token 无效 | Tushare Token 无效，请检查配置 |
| API 限流 | API 调用频率超限，请稍后重试 |
| 基金代码不存在 | 基金代码不存在 |
| 数据验证失败 | 具体验证错误信息 |
