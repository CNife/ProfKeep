# 01 - FundKeeper TUI MVP

> **状态**: 待开始
> **来源**: GitHub Issue #1

## Problem Statement

作为个人投资者，我需要一个简单、高效的工具来管理我的基金账户。现有方案存在以下问题：

1. **数据隐私**：第三方基金记账应用需要上传数据到云端，存在隐私风险
2. **操作效率**：Web 应用需要打开浏览器、登录，操作步骤繁琐
3. **定制需求**：现有工具无法满足我的个性化需求（如特定的成本计算方式、收益曲线展示等）
4. **学习目的**：我希望通过这个项目学习 Python TUI 开发

## Solution

开发一个基于 Textual 的终端用户界面（TUI）应用，实现：

- 本地 SQLite 数据库存储，数据完全由用户控制
- 单体应用架构，无需前后端分离
- 通过 `uv tool install` 一键安装
- Vim 风格的快捷键设计，高效操作

4. 作为投资者，删除账户时，我希望同时删除该账户的所有交易记录和持仓数据，以便彻底清理

## Implementation Decisions

### 架构决策

1. **技术栈**：Python 3.11+ + Textual + SQLAlchemy + SQLite + Tushare
2. **架构模式**：单体应用，无前后端分离
3. **数据存储**：本地 SQLite，路径 `~/.fundkeeper/data.db`
4. **安装方式**：`uv tool install fund-keeper`

### 持仓计算

5. **成本计算方法**：平均成本法
   - 持仓成本 = Σ(买入金额 - 卖出金额) ÷ 当前持仓份额
   - 不追踪每笔卖出对应哪笔买入
6. **分红处理**：支持现金分红和红利再投资两种方式
   - 现金分红：记录金额，份额不变
   - 红利再投资：记录份额和金额，份额增加

### 交易记录

7. **交易类型**：买入 (buy)、卖出 (sell)、现金分红 (dividend_cash)、红利再投资 (dividend_reinvest)
8. **确认状态**：每笔交易有确认状态字段
   - 已确认：计入持仓计算
   - 未确认：不计入持仓，仅作记录

### 净值获取

9. **刷新策略**：仅手动刷新（按 r 键），不自动刷新
10. **缓存时间**：净值数据缓存 7 天
11. **限流处理**：Tushare 免费版限制每分钟 200 次，实现 0.3 秒间隔的限流器
12. **基金信息自动补全**：输入 6 位基金代码后自动查询并显示基金名称

### 数据验证

13. **验证时机**：提交时验证所有字段
14. **验证规则**：
    - 基金代码：必须为 6 位数字
    - 份额：必须为正数，最多 4 位小数
    - 金额：必须为正数，最多 2 位小数
    - 日期：必须为有效日期格式

### 数据导入导出

15. **CSV 格式**：固定格式模板，包含表头
16. **导出内容**：当前账户的所有交易记录
17. **导入校验**：检查格式、数据类型、外键约束

### 用户界面

18. **页面导航**：a(账户)、h(持仓)、t(交易)、c(图表)
19. **列表操作**：n(新增)、e(编辑)、d(删除)
20. **全局操作**：r(刷新净值)、?(帮助)、q(退出)
21. **列表导航**：j/k 上下移动，Enter 确认，Esc 取消
22. **收益曲线时间范围**：Tab 键在 1 个月/6 个月/1 年/全部间切换
23. **错误展示**：弹窗模态框显示错误信息

### 账户删除

24. **删除策略**：级联删除，删除账户时同时删除所有关联的交易记录和持仓数据

### 帮助界面

25. **帮助内容**：仅展示快捷键列表，不包含详细操作指南

## Testing Decisions

### 测试原则

- 仅测试外部行为，不测试实现细节
- 测试边界条件和错误处理
- 使用 pytest 作为测试框架

### 测试范围

**数据层（models/）**

- 模型字段约束验证
- 外键关联正确性
- 唯一性约束验证

**服务层（services/）**

- AccountService: CRUD 操作
- HoldingService: 持仓计算、汇总逻辑
- TransactionService: 交易记录管理、确认状态影响
- NavService: 缓存管理逻辑

**业务逻辑层（utils/）**

- CostCalculator: 平均成本计算，多笔买卖场景
- ReturnCalculator: 收益率计算，正负收益场景
- CsvHandler: CSV 格式验证、导入导出

**不测试**

- UI 层（screens/）：TUI 组件测试复杂度高，暂不覆盖
- Tushare API：外部依赖，使用 Mock 测试服务层

## Out of Scope

以下功能不在 MVP 范围内：

1. **饼图**：用柱状图替代（后续迭代）
2. **Web/浏览器集成**：纯 TUI 应用
3. **其他基金软件数据导入**：如天天基金、蛋卷基金等
4. **Windows 特定优化**：主要支持 Linux 和 macOS
5. **自动净值刷新**：仅支持手动刷新
6. **自动数据备份**：CSV 导出已满足备份需求
7. **多币种/多市场**：仅支持人民币基金
8. **实时净值推送**：仅支持手动查询
9. **PDF 报告导出**：后续迭代
10. **Excel 导出**：后续迭代
